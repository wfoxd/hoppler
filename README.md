# Hoppler

Mesh Life Platform — the app. Flutter UI over a Rust core (`rust/`, crate `rust_lib_hoppler`), bridged with flutter_rust_bridge v2. Concept and design docs live in the parent project's `docs/` (not in this repo yet).

## Layout

```
lib/            Flutter app (Dart). lib/src/rust/ = generated bridge; lib/src/gen/ = generated protobuf
rust/           libhoppler core crate (Rust); rust/src/api/ is the bridge surface
rust_builder/   cargokit glue (generated by flutter_rust_bridge integrate)
proto/          protobuf schemas (source of truth for wire types)
integration_test/  on-device tests (needs a real device/emulator)
scripts/        setup.sh (environment), gen-proto.sh (Dart proto codegen)
```

## Getting started

```sh
make setup   # checks/installs toolchain; prints the one sudo command it can't run itself
make run     # Linux desktop — the everyday dev loop (radios are faked until T07+)
make ci      # lint + tests + codegen-drift check; keep green before pushing
```

Toolchain (pinned): Flutter 3.44.0 stable · Rust stable · flutter_rust_bridge_codegen 2.12.0 · protoc ≥ 3.x with protoc-gen-dart.

Changed the Rust API surface (`rust/src/api/`) or `proto/`? Run `make gen` and commit the regenerated files — CI fails on drift.

## Troubleshooting

- **`flutter_rust_bridge_codegen: command not found`** — `~/.cargo/bin` is not on PATH; `make` targets export it, or run `make setup`.
- **Android build fails** — you need JDK 21 + Android SDK (`ANDROID_HOME`); see `scripts/setup.sh` output.
- **Linux desktop build fails** — missing `cmake`/`ninja` (see setup.sh sudo line).
- **FVM users** — the project expects Flutter 3.44.0; `fvm use 3.44.0` if your default differs.

Task provenance: this scaffold is T03 of Ring 0 — see `docs/ring0/` in the parent project.
